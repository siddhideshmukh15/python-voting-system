# python-voting-system


A simple **Voting System** built using Python. This beginner-friendly project allows users to vote for candidates and view the voting results.

## Features

- Display available candidates
- Cast a vote
- Prevent duplicate voting using voter ID
- Count votes for each candidate
- View voting results
- Exit the system

## Technologies Used

- Python
- Dictionaries
- Sets
- `while` loop
- `for` loop
- `if-elif-else` statements
- User input

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the program:

    python voting-system.py
